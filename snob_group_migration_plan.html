Section 07Admin Portal Design

The admin portal replaces wp-admin with a purpose-built, WordPress-like experience for non-technical users. It is a separate Next.js app that shares the same FastAPI backend.

Design Principles

  • WordPress-familiar UX: Left sidebar navigation, top bar with quick actions, familiar CRUD patterns — staff who know WordPress will feel at home
  • WYSIWYG Content Editing: Rich text editor (Tiptap or Plate.js) with drag-and-drop block-based editing for pages and product descriptions
  • Inline Media Management: Drag-and-drop image/video uploads directly into content, integrated media library with search and folders
  • Real-time Autosave: Draft and revision history for all content, with one-click restore
  • Role-Based Views: Each admin role sees only the sections they have permission to access

Content Editor (WordPress-like)

The page and product editor uses a block-based WYSIWYG approach:

  • Block Types: Heading, paragraph, image, video, gallery, button, columns, spacer, HTML embed, product grid, event calendar, form, testimonial, FAQ accordion, pricing table
  • Drag-and-Drop: Reorder blocks by dragging, nest blocks inside columns
  • Inline Styling: Font, color, spacing, alignment controls per block — no code needed
  • Templates: Pre-built page templates (landing page, product page, about page, contact page)
  • Preview: Live preview before publishing, desktop/tablet/mobile toggles
  • Revision History: Every save creates a revision; compare diffs and restore any previous version
  • Scheduling: Schedule publish/unpublish dates for pages and products

Contact Management

  • Import contacts from CSV, sync from user database, manual entry
  • Custom fields per contact (name, membership tier, tags)
  • Smart lists: dynamic lists based on filters (e.g., “all Executive members”, “users who booked in last 30 days”)
  • Static lists: manually curated groups

Template Builder

  • Reusable message templates with merge fields: {first_name}, {membership_tier}, {next_event}, {wallet_balance}
  • Character count with SMS segment calculator (160 char / 70 char unicode awareness)
  • Template categories: promotional, transactional, appointment reminder, event notification, LMS update

Campaign Builder

  • Select audience (one or more contact lists, or smart filter)
  • Choose or compose message (from template or freeform)
  • Schedule: send now, send later (date/time with timezone), or recurring (daily/weekly/monthly)
  • A/B testing: split audience and test two message variants
  • Preview: see personalized message for sample contacts before sending

Delivery & Analytics

  • Real-time delivery status: queued, sent, delivered, failed, bounced
  • Per-campaign metrics: delivery rate, failure rate, opt-out rate, cost
  • Per-contact delivery history
  • Exportable reports (CSV/PDF)

Compliance & Opt-Out

  • Automatic STOP/unsubscribe handling (TCPA/CTIA compliant)
  • Opt-out list enforced on every send — opted-out contacts are never messaged
  • Opt-in confirmation flow for new contacts
  • Quiet hours enforcement (no messages outside configurable hours per timezone)
  • Consent tracking with timestamps

Section 09Security Hardening

Authentication
JWT with short-lived access tokens (15 min) + refresh tokens (httpOnly cookies), bcrypt password hashing
Authorization
RBAC with middleware enforcement on every endpoint
Input Validation
Pydantic models validate all API input; parameterized SQL queries via SQLAlchemy ORM
Rate Limiting
Redis-backed rate limiting on auth endpoints, API throttling per user
CSRF / XSS
SameSite cookies, Content Security Policy headers, automatic HTML escaping
Secrets Management
Environment variables via .env files (dev), cloud secrets manager (prod)
Audit Logging
All admin actions, payment events, and auth events logged with timestamps and actor
File Upload Security
File type validation, virus scanning, size limits, signed upload URLs
API Security
CORS whitelist, request size limits, SQL injection prevention, header hardening
Infrastructure
HTTPS enforced, HTTP Strict Transport Security, automated SSL via Let's Encrypt or Cloudflare

Section 10Migration Strategy

10 phases over 24 weeks, from foundation to launch.

Phase 1: Foundation
Weeks 1–3
  • Project scaffolding: FastAPI backend, Next.js frontend, Docker Compose, PostgreSQL, Redis
  • Database schema design and Alembic migrations
  • Auth system: registration, login, social OAuth, JWT, 2FA/OTP, RBAC
  • Media service: S3/R2 upload, image processing, CDN integration
Phase 2: Admin Portal Foundation
Weeks 4–5
  • Admin portal scaffolding (Next.js app with sidebar navigation, RBAC route guards)
  • WYSIWYG block editor component (Tiptap or Plate.js) with drag-and-drop blocks
  • Media library: upload, organize, search, inline insertion into editor
  • Page editor: create/edit/publish pages with revision history, preview, scheduling
  • Menu builder: drag-and-drop menu management
  • SEO panel: per-page meta tags, Open Graph, JSON-LD editing
  • Global settings panel
Phase 3: Commerce Core
Weeks 6–8
  • Unified product model: physical, digital, subscription, event product types
  • Product manager in admin portal: WYSIWYG description editor, image gallery, pricing, inventory, bulk actions, CSV import/export
  • Event-specific admin: date/venue/capacity/RSVP/ticketing, calendar admin view, drag-to-reschedule, attendee management
  • Cart and checkout flow with Stripe Payment Intents
  • Subscription management via Stripe Billing
  • Membership plans: Founders ($15K), Signature ($20K), Prestige ($35K), Executive ($45K)
  • Wallet system with auto-top-up logic (SKU SG-SUIT-006)
  • Order management admin: order list, detail view, refunds, status updates
  • Coupon and pricing rules admin
Phase 4: Communications — Email & SMS
Weeks 9–10
  • Email system: transactional emails (Resend/SendGrid), newsletter campaign builder in admin
  • SMS system backend: Twilio/Vonage integration, task queue (Celery + Redis), rate limiting
  • SMS contact management: import, sync from users, smart lists, static lists, custom fields
  • SMS template builder: merge fields, character/segment calculator, template categories
  • SMS campaign builder: audience selection, scheduling, A/B testing, preview
  • SMS delivery tracking: real-time status, per-campaign analytics, exportable reports
  • Compliance: STOP handling, opt-out list enforcement, quiet hours, consent tracking
  • Automated SMS triggers: order confirmations, appointment reminders, event reminders, membership renewals, LMS notifications, 2FA/OTP
Phase 5: Booking & Events Frontend
Week 11
  • Booking module: resources, slots, appointments, My Account integration
  • Event calendar frontend: agenda/month/week/grid views, RSVP flow, ticket purchase
  • Booking admin: resource/slot management, booking list, calendar view
  • Event attendee management admin: check-in, export, ticket sales dashboard
Phase 6: LMS
Weeks 12–15
  • Course/module/lesson data model and CRUD API
  • Course builder in admin portal: WYSIWYG lesson editor, module/lesson ordering, media upload
  • Video upload and streaming integration (Mux/Cloudflare Stream)
  • Quiz engine: question types, auto-grading, attempt tracking, quiz builder in admin
  • Enrollment and progress tracking with admin analytics dashboard
  • Cohort management: creation, member assignment, shared timelines
  • Discussion forums: threaded posts, instructor tools
  • Live session scheduling and recording integration
  • Certificate generation (PDF) with admin template editor
  • Content gating by membership tier
Phase 7: User Management & Admin Completion
Week 16
  • User list: search, filter (role/membership/dates), sortable, paginated
  • User profile admin: edit profile, view full history (orders, subscriptions, memberships, wallet, LMS, bookings)
  • Admin notes per user (private, admin-only)
  • User impersonation (login-as-user)
  • Role and permission editor
  • Audit log viewer: all admin actions, payment events, auth events with filtering and export
  • Backup manager: trigger and download PostgreSQL backups
  • Admin dashboard: KPI widgets (revenue, users, orders, active memberships, LMS enrollment, SMS delivery stats)
Phase 8: Public Frontend Recreation
Weeks 17–20
  • Pixel-match the current Elementor-built pages in Next.js + Tailwind
  • Home page, product pages, category pages, checkout flow
  • My Account area: orders, subscriptions, memberships, bookings, wallet, LMS dashboard
  • Event calendar views (public-facing)
  • Responsive design (mobile-first, matching current breakpoints)
  • GTM/analytics integration
Phase 9: Data Migration
Week 21
  • Write migration scripts to transfer from MySQL (agh_ prefix) to PostgreSQL
  • Migrate: users (528), products, orders, subscriptions, memberships, wallet balances, bookings, events, media files
  • URL redirect mapping (old WordPress URLs to new routes)
  • SEO preservation: 301 redirects, meta tags, sitemap
Phase 10: Testing & Launch
Weeks 22–24
  • End-to-end testing: auth flows, purchase flows, subscription billing, booking, LMS enrollment, SMS campaigns
  • Admin portal UAT: content editors test page/product/event editing workflows
  • Performance testing: load testing API endpoints, frontend Lighthouse scores
  • Security audit: OWASP top 10 checklist, penetration testing
  • Side-by-side comparison with live WordPress site
  • Staging deployment, UAT with real users
  • DNS cutover, monitoring setup (Sentry, uptime checks)
